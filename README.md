# RoboSkillX

## About the Project

RoboSkillX is an online robotics skill development platform designed to help learners gain practical robotics knowledge through courses, simulations, projects, mentorship, and live sessions. The platform connects learners, mentors and administrators in a single ecosystem for robotics education.

## Features

### Learner Features

- User Registration and Login
- Personalized Onboarding
- Enroll in Robotics Courses
- Beginner,Intermediate,and Advanced Course Levels
- Secure Course Payment System
- Watch Session Videos and Learning Materials
- Attend Live SSesssions
- One-to-One Mentoring Sessions
- Chat with Mentors
- Complete Quizzers
- Track Learning Progress
- Simulation Lab
- Design and Test Robotics Project Prototype Virtually
- Project Submission and Evaluation

### Mentor Features

- Mentor Registration and Approval Process
- Manage Sessions
- Conduct Live One-to-One Mentoring Sessions
- Chat with Learners
- View Scheduled Sessions
- Earnings Dashboard
- Wallet Management
- Course completion earning credited to mentor wallet
- Withdraw earnings from wallet

### Admin features

- Admin Dashboard
- Create, Update, and Manage Courses
- Create and Manage Sessions
- Mentor Approval and Management
- Learner Management
- Payment Management
- Wallet and Payout Management
- Track Course Sales and Earnings

### Simulation Lab

The Simulation Lab allowes learners to:

- Build virtual robotics project
- Design project prototypes before hardware implimentation
- Experiment with circuits
